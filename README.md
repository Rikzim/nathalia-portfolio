# underdog51 — portfólio

Portfólio de Nathalia Michalzuk, com React, Vite e animações GSAP/ScrollTrigger.

## Rodar localmente

```bash
npm install
npm run dev
```

As artes estão em `public/artworks`. O arquivo `src/App.jsx` concentra a lista de obras e os filtros da galeria. A seção de contato está sem links até os canais serem definidos.
